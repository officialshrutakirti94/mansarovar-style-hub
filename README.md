# Mansarovar Style Hub

Build a modern, premium, responsive retail fashion website for Mansarovar Readymade.

I will provide the shop logo and shop photo. Use them prominently and naturally throughout the design.

Website Structure

1. Hero Section

Use the provided shop image as the main visual.

Display the Mansarovar Readymade logo prominently.

Add a strong headline such as “Style for Everyone, All in One Place.”

Add a short subtitle describing the store as a readymade clothing destination for men, women, and kids.

Include a clear “Explore Collections” CTA.

Add tasteful vector/line animations, floating clothing-related shapes, or subtle fashion illustrations.

Keep animations smooth, elegant, and lightweight.

2. Categories Section
Create three main category cards:

👔 Men's Wear

👗 Ladies' Wear

🧒 Kids' Wear

Boys

Girls

Each category should have an attractive visual/card layout with subtle hover animations.

3. About / Store Section
Briefly introduce Mansarovar Readymade as a trusted local readymade clothing store offering fashionable and comfortable clothing for the whole family.

4. Contact Us
Include:

📞 Mobile number: [ADD NUMBER]

📧 Email: [ADD EMAIL]

Facebook: [ADD LINK]

Instagram: [ADD LINK]

YouTube: [ADD LINK]

Add clickable social media icons and contact links.

Design Direction

Modern, elegant fashion-store aesthetic.

Clean typography with a premium but welcoming feel.

Responsive on mobile, tablet, and desktop.

Use subtle gradients, glassmorphism where appropriate, smooth scrolling, hover effects, and tasteful micro-interactions.

Use the provided logo's colors as the primary brand palette.

Avoid making the website look overly corporate; it should feel like a real local fashion store with a premium digital presence.

Add a clean footer containing the logo, navigation links, social icons, and contact information.
